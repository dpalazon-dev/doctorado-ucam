# Research Workbench prototype

This imported namespace is a partial Windows desktop prototype, paused because its author currently has no time for active maintenance. Its files describe the Workbench project and its own historical contracts; they are not ResearchOS specifications and do not define ResearchOS architecture or canonical domain semantics.

Before changing this prototype, read its [`INTENT.md`](INTENT.md), [`docs/STATUS.md`](docs/STATUS.md), and the relevant documents in [`docs/architecture/`](docs/architecture/). Preserve its independent contracts. Do not infer a completed release, installation validation, active support, or a commitment to respond to issues from its public availability.

The prototype targets Windows 11 x64 and contains no AI sidecar. ResearchOS at repository root is a future, multiplatform vision with optional Python cognitive processing. These are separate scopes.
