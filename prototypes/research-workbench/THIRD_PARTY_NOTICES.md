## Incorporation notes

## PDF.js reader resources

The desktop bundle includes `pdfjs-dist` 6.3.289 code and worker under Apache-2.0. Its bundled CMaps, ICC profiles, standard fonts and WebAssembly decoders are copied from that same pinned package into `dist/pdfjs/`; the package and per-resource license notices (`cmaps/LICENSE`, `iccs/LICENSE`, `standard_fonts/LICENSE_FOXIT`, `standard_fonts/LICENSE_LIBERATION`, and the `wasm/LICENSE_*` files) ship alongside those resources. These assets are loaded only from the installed bundle; the application does not contact a PDF.js CDN.

`src/shared/ui/dialog.tsx` is a project-owned shadcn/ui-style component composed from Radix primitives. Radix is MIT licensed. No shadcn CLI, theme generator, store or additional styling framework is installed. PDF.js and its worker ship as local Vite assets; no CDN is used.

Support crates (`serde`, `serde_json`, `uuid`, `chrono`, `sha2`, `fs2`, `tokio`, `tempfile`) implement required wire encoding, identifiers/time, hashing, OS lock, asynchronous actor reply and isolated tests. They add no application network, shell or frontend filesystem capability.

T01 fix round 1 promotes the existing `tempfile` package to runtime for RAII-owned, external schema-diagnostic scratch when SQLite WAL/journal is pending. No new package or version is introduced; the scratch contains DB/sidecars only, not PDFs or a public backup feature.
