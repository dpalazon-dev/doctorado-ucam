# Research Workbench 0.0.1 — local pilot

This milestone packages the Windows x64 desktop app using per-user NSIS. Configuration includes WebView2 in `offlineInstaller` mode; PDF.js resources are local to the frontend. Actual offline operation remains pending verification of the resulting installer.

The pilot covers installation preparation and verification of the Library/Reader flow: import a synthetic PDF, move the original, reopen reading and archive/restore. Evidence for each journey is recorded in [installed-pilot.md](../verification/installed-pilot.md).

The library and its files remain outside the binaries under `%LOCALAPPDATA%\ResearchWorkbench`. Before updating or uninstalling, save a copy of the library and its backups. No integrated updater or Authenticode signature is provided. Reinstalling this version does not establish migration. v0.1 and later features are outside this pilot.
